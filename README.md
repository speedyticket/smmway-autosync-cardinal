# smmway-autosync-cardinal
SMMWay price autosync plugin for FunPayCardinal
# SMMWay AutoSync для FunPayCardinal

Плагин для автоматической синхронизации цен FunPay-лотов с услугами **SMMWay**.

Берёт актуальную стоимость услуги через API SMMWay, рассчитывает цену лота с учётом количества и множителя и обновляет её на FunPay.

## Возможности

- автоматическое обновление цен по заданному интервалу;
- ручной запуск синхронизации;
- предпросмотр изменений без сохранения;
- повышение и снижение цен;
- настраиваемый множитель;
- порог изменения цены;
- диагностика удалённых или недоступных service ID;
- уведомления об ошибках и проблемных лотах;
- повтор запросов при временных ошибках SMMWay/FunPay;
- защита от одновременного запуска нескольких обходов;
- работа с русским и английским описанием лота.

Плагин **не заменяет service ID автоматически**. Если услуга пропала из каталога SMMWay, соответствующий лот не изменяется, а пользователь получает уведомление.

---

## Установка

1. Скачайте `autosync.py`.
2. Установите его как обычный плагин FunPayCardinal.
3. Перезапустите Cardinal.
4. Откройте Telegram-бота Cardinal и отправьте:

```text
/smmsync
```

5. Укажите API-ключ SMMWay и настройте множитель.

Если у вас уже установлен другой плагин автоматического изменения цен, например Shadow AutoPrice, его автообход лучше отключить. Два разных плагина не должны одновременно менять цены одних и тех же лотов.

---

## Формат описания лота

Пример:

```text
smm: on
id: 1234
name: way
am: 100
```

Где:

- `id` — ID услуги в SMMWay;
- `name` — используемый SMM-провайдер (`way` или `smmway`);
- `am` — количество единиц услуги в одном лоте;
- `smm: on` — разрешает AutoSync обрабатывать этот лот в стандартном режиме.

Минимально можно использовать:

```text
smm: on
id: 1234
```

Если `am` не указан, используется значение `1`.

Также поддерживаются альтернативные названия полей, используемые AutoSMM:

```text
service_id
service

quantity
qty
количество

service_name
provider
```

Лот с:

```text
smm: off
```

никогда не будет изменён.

## Расчёт цены

Цена рассчитывается по формуле:

```text
цена услуги за 1000 / 1000 × am × множитель
```

Например:

```text
Цена SMMWay: 50 ₽ / 1000
am: 100
Множитель: 1.5
```

Итог:

```text
50 / 1000 × 100 × 1.5 = 7.5 ₽
```

После расчёта цена приводится к формату FunPay: **3 знака после запятой с округлением вверх**.

Примеры:

```text
0.0541 → 0.055
0.0098 → 0.010
0.0042 → 0.005
0.0003 → 0.001
```

Именно эта итоговая цена используется и в предпросмотре, и при сохранении лота.

## Telegram-меню

Основное управление находится в `/smmsync`.

На главной странице доступны:

```text
Автосинк
Множитель
Запустить сейчас
Предпросмотр
Мёртвые ID
Настройки
```

В настройках находятся:

```text
Интервал
Уведомления
API-ключ
Направление изменения цены
Порог
Область лотов
```

### Предпросмотр

Позволяет посмотреть, какие цены изменились бы, **не сохраняя изменения на FunPay**.

Удобно использовать после изменения множителя или перед первым запуском плагина.

### Мёртвые ID

Показывает лоты, service ID которых больше нет в текущем каталоге SMMWay.

Плагин не пытается угадывать замену и не изменяет описание такого лота.

---

## Порог изменения цены

Порог определяет минимальную разницу, при которой цена будет сохранена.

Например, при пороге:

```text
0.1
```

изменение:

```text
10.00 → 10.05
```

будет пропущено, а:

```text
10.00 → 10.15
```

будет применено.

Если нужен максимально точный автосинк, можно установить:

```text
0
```

В этом случае цена обновляется при любом изменении итоговой цены FunPay.

---

## Направление изменения цены

Доступны два режима:

**В обе стороны**  
Цена может как повышаться, так и снижаться вслед за SMMWay.

**Только вверх**  
Плагин повышает цену при росте себестоимости, но не снижает её.

---

## Область лотов

По умолчанию плагин работает только с лотами, где явно указано:

```text
smm: on
```

Также можно включить режим обработки всех распознанных SMMWay-лотов.

Лоты других SMM-провайдеров не изменяются.

---

## Уведомления

Обычные успешные автоматические обходы можно отключить в настройках.

При этом важные проблемы всё равно отправляются в Telegram, например:

- service ID больше не существует;
- описание лота некорректно;
- не удалось прочитать или сохранить лот;
- SMMWay API недоступен;
- цена не может быть корректно рассчитана;
- лот изменился во время обхода.

Проблемные лоты выводятся одним итоговым сообщением, без спама отдельными уведомлениями.

## Требования

- FunPayCardinal;
- Python 3.10+;
- API-ключ SMMWay.

Дополнительные зависимости отдельно устанавливать обычно не требуется — используются библиотеки, уже применяемые FunPayCardinal.
